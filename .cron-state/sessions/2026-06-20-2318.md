## Notable design decisions

- `next --json` schema is omitempty-clean — the `empty` key NEVER
  appears on a successful pick, so `jq '.empty'` reliably branches
  vs string-matching "all caught up".
- `topo` uses Kahn's algorithm; inside-layer tie-break matches
  `tsk next`/`top` so the head of topo === `next --respect-deps`.
  Cycle leftovers emit at the tail with "(cycle)" — never silently
  dropped.
- `path` BFS uses parent-map reconstruction (O(V) memory). Strict
  a → b direction; silentExit(1) on no-match so the human-readable
  line stands alone.
- `graph --reachable` empty-from-root gets a specific message
  ("no dependencies reachable from #N") rather than the generic
  whole-store empty text. Fan-in semantic: siblings that ALSO
  depend on the same prereq are NOT pulled in — only ancestors
  of the queried root.
- `depend --justify` walks lowest-id open prereq at each step
  (deterministic). Status state-machine encoded in one field:
  done / no-deps / open-leaf / blocked / cycle / missing. Root-
  vs-mid context switches "no-deps" vs "open-leaf" classification
  via an isRoot bool tracked through the loop.
