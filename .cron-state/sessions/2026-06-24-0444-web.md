- Backend CRUD (`POST/PATCH/DELETE/toggle`) already existed from T1, so all
  five are frontend slices over the same JSON API + `.tsk.md` store.
- Each slice carries a **pure, dependency-free logic module** that's unit
  tested under Node's native TS runner: `quickadd.ts`, `composer.ts`,
  `sections.ts`, `keynav.ts`, `toast.ts`, `edit.ts`. 48 frontend tests total.

  tsconfig, `@types/node` (devDependency, NOT bundled — production build is
  unchanged), and npm scripts `test` / `typecheck:test` / `check`.

  hotkeys (j/k/x/e) stand down while typing in a row.
