## What shipped

- `tsk elapsed [id]` — elapsed-time view for in-progress tasks
  (staleness ordering for the list form, JSON elapsed_seconds for
  scripts, single-id JSON is an object for `jq -r .elapsed_seconds`,
  clock-skew clamps to 0).
- `tsk why <id>` — chronological provenance trail (timeline sibling
  of `show` snapshot and `diff` delta). Created/started/waited/due/
  completed events sorted chronologically with relative annotations.
  Done tasks suppress overdue framing.
- `tsk shuffle [N]` — decision-paralysis breaker. Partial Fisher-
  Yates without replacement, --seed determinism, --tag/--priority
  filters compose via AND, default scope matches top/next.
- `tsk find <regex>` — title-only RE2 search. Fast cousin of grep
  (skips notes scan). compileGrepPattern reused so case-fold
  semantics can't drift. Mutually-exclusive output modes guarded.
- `tsk depend <id>` — task dependencies with done-blocking. New
  Task.DependsOn storage field, parser/writer/lint/hash extended.
  toggle.go pre-flights every batch id; blocked ids abort the
  whole batch (exit 2, no partial state). Same-batch satisfaction
  so `tsk done 1 2` works when 2 depends on 1. Self-deps + direct
  cycles rejected; 3+-node cycles intentionally undetected.
  Dangling deps tolerated at runtime (lint surfaces them).
