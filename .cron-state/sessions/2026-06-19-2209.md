## Notable design choices worth remembering

- **`reopen` is more than an alias.** The roadmap asked for an alias
  for `undo`, but plain aliases are filler. Added two ergonomic modes
  `undo` doesn't have: `--last` (most recent completion) and
  `--since <dur>` (everything completed in a window). The three modes
  (ids, --last, --since) are mutually exclusive.
- **Local duration parser in reopen.go.** `store.ParseDuration` treats
  `m` as months (built for archive/purge windows). Reopen needs minutes
  — `--since 5m` MUST mean 5 minutes, not 5 months. The local parser
  tries `time.ParseDuration` first (handles `1h30m`), then s/m/h/d/w
  shorthand, then bare integer → seconds. Dedicated regression test
  (`TestReopenSinceMinutesNotMonths`) guards against accidentally
  switching to the store helper later.
- **`snooze`'s no-backward guard.** Refuses to move a due date
  backward by default. Use `tsk due` for arbitrary set, or pass
  `--force` to snooze. Special case: undated task degrades to plain
  set with an "(initial)" marker so the verb stays useful.
- **`note`'s editor indirection.** `var noteEditor = invokeEditor` lets
  tests swap the editor for a deterministic shim (with `withNoteEditor`
  helper) without forking a subprocess or relying on $EDITOR. Pattern
  worth re-using for any other command that needs an editor flow.
- **`clone` deep-copies tags + due pointer.** A regression test
  (`TestCloneDoesNotShareTagBackingArray`) verifies mutating the
  source's tags after cloning doesn't bleed into the clone. Cheap
  insurance against a subtle aliasing bug.
- **Empty editor save in note.** Treated as a clear (with explicit
  "cleared" message), NOT a silent wipe. If you open the editor and
  immediately :q without changes, you still get visible feedback.
