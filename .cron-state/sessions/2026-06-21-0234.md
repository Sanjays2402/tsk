## Theme

Discoverability + entry-point polish for the dep cluster shipped
in ticks #9–#11:

- `show --tree` folds two commands (`show` + `depend --tree`) into
  one keystroke for the triage-a-blocked-task moment.
- `depend --upstream` is the inverse-of-tree question — answers
  "what depends on me?" with per-row (unblocks)/(blocked)/(done)
  classification so users can see what closing a task would
  actually trigger downstream.
- `reachable <id>` surfaces the existing `graph --reachable` filter
  as a top-level command (same pattern tick #10 used for `blocked`)
  so it appears in `--help` and shell completion.
- `next --skip` adds the "no thanks, runner-up" filter that doesn't
  need persistent pin/freeze state — composes with --respect-deps.
- `add --depends` removes the two-step "add then depend" dance at
  task creation, with full rollback if validation fails so a typo
  never lands a half-formed task.
