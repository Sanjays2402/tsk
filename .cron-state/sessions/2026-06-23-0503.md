## Features

1. `tsk archive --json --output <path>` — write the JSON envelope
   to a file (sister of `tsk graph --json --output`). Same
   buffer-then-write atomic-write contract, .json extension
   validation (case-insensitive), three exit-path coverage
   (no-tasks / dry-run / real-run). 9 tests. **SHA: f6dd3d2**

2. `tsk archive --json --output <path> --append` — JSONL streaming
   for archive runs. Each call adds one compact record to a
   .jsonl/.json file (O_APPEND open, never truncates). Builds a
   chronological log of "what shipped" for velocity tracking and
   anomaly spotting. Sister of `tsk graph --json --output --append`
   shipped tick #25. 10 tests. **SHA: 4d841ad**

3. `tsk graph --json --include-tags` — second opt-in node field
   in the include-* family (priority shipped tick #26 was first).
   Modeled as *[]string to distinguish "field absent (flag off)"
   from "field present and empty []" — the empty-array contract
   matters for jq's `.tags | length`. Composes with --include-
   priority, --compact-json, --append. 9 tests. **SHA: 8b39bc9**

4. `tsk graph --json --include-due` — third opt-in node field
   (YYYY-MM-DD string; omitempty drops the empty string when a
   task has no due). The ISO format makes lexicographic string
   comparison equivalent to date comparison — verified by a
   dedicated test. Composes with priority + tags + compact-json
   + append. 9 tests. **SHA: 2933638**

5. `tsk pause --all --strict-and-tag a,b` — CSV intersection-
   style tag filter (sister of `tsk depend --pending
   --strict-and-tag` shipped tick #26 — same flag name on the
   bulk-pause surface). Mutually exclusive with --tag, composes
   with --priority as AND. JSON dry-run surfaces both the
   structured "strict_and_tag" key and the human "filter" summary
   with the &-disambiguation marker. New buildPauseAllFilterSummary
   helper keeps the two filter-summary trees (pending + pause)
   independently revertible. 11 tests. **SHA: 7f45992**
