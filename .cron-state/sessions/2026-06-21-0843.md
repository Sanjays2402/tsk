## Per-feature notes

- `lint --dep-cycles`: Tarjan SCC. Skips 2-node SCCs (rejected at
  write time). Reconstructs the canonical cycle chain by following
  directed edges from the smallest-id rotation start so output is
  reproducible. Opt-in flag keeps default `tsk lint` fast.

- `topo --since`: strict "id must already be in topo output"
  contract; usage-2 error message names --all explicitly when
  applicable. Cycle-tail anchor supported defensively. Helper
  re-appends pre-checkpoint cycle rows at the new tail.

- `archive --strategy weekly`: layout-only — never re-buckets
  existing archive content. `## undated` catches timestamp-less
  done tasks. Buckets sort oldest-first; "undated" explicitly to
  the tail. Local renderArchiveMeta/Task dups (store.render* are
  unexported) keep archive layout decoupled from public API surface.

- `depend --pending --tag`: HasTag predicate (same as ls/top).
  Empty value is a no-op to defend against shell-var typos.
  Header annotation includes tag when active.

- `preview`: new `store.LoadBytes` exported helper (parse without
  filesystem). Reuses lsFilters surface so no second filter system.
  --respect-deps walks the snapshot's own graph. 4 MiB cap on
  input via io.LimitReader; empty input is exit-2.
