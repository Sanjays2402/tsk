## Notable design calls (one-liners; deep rationale in commit bodies)

- `hash --semantic` projects in ID order and UTC for timezone-
  invariance; notes are escape-encoded so literal `\n` and real
  newlines hash distinctly.
- `pri-stats` always emits all 4 buckets so the user sees the zeros;
  the `--bar` floor is one █ for any non-zero count.
- `freeze` is a pure shim on `wait` (sentinel 2099-12-31); no new
  persisted state, so all existing wait machinery works untouched.
- `dedupe` is review-only (no auto-delete); Levenshtein with early
  termination on row min > cap; greedy clustering for --near mode.
- `start`/`stop` are idempotent without --reset (don't zero elapsed
  time on accidental re-run); `done` clears Started (Completed wins
  on a finished task); starting a DONE task is a usage error
  (reopen first).
