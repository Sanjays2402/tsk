## Notable techniques worth re-using

- **`extractFileFlag` helper in tag.go**: for any future command whose
  positional args start with `-` (e.g. a `tsk filter -done` style),
  set `DisableFlagParsing: true` on the cmd and call extractFileFlag
  on the raw args before parsing your own. Keeps the global `--file`
  flag working without cobra eating your args.
- **`parseSingleID`** in show.go: small wrapper around `parseTaskIDs`
  that enforces exactly-one and returns a usage-coded (exit 2) error.
  Used by show/pri/due — should be the standard for all single-task
  commands going forward.
- **`saver` interface in due.go**: trivial 1-method interface around
  `Save()` so the run helpers stay easy to fake in tests if we ever
  need to. Costs nothing, opens the door later.
