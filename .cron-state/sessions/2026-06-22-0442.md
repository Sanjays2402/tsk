## Notable choices

- The bulk-action verb cluster is now fully symmetric: `start --all`
  and `pause --all` both have filter + dry-run + JSON variants. The
  JSON envelope deliberately uses different array names (`would_pause`
  vs `would_start`) so jq pipelines can identify the source verb
  without an extra field, but the rest of the schema is identical
  so pipelines can compose.

- `graph --upstream-of` closes the bidirectional subgraph extraction
  story for tsk's dependency model. `--reachable` answers "what must
  finish before #id?"; `--upstream-of` answers "what's still blocked
  by #id?". The both-endpoints edge filter (vs --reachable's source-
  in-set filter) is the critical correctness invariant — without it,
  the rendered subgraph would include off-chain prereqs that dilute
  the impact-analysis view. Tested by the explicit off-chain-exclusion
  case.

- TUI `g`/`G` is the first vim-nav binding to land. Bound to both vim
  keys AND home/end conventional keys for discoverability. Form-active
  branch runs FIRST so the chars get buffered as text during add/edit
  (regression-tested by typing 'g' as part of a new task title).

- `lint --autofix-all --backup <dir>` solves pre-commit ergonomics:
  the default in-place .bak dirties the working tree; --backup
  redirects to a timestamped file inside an explicit directory and
  removes the in-place .bak afterward. Trade-off documented: this
  breaks `tsk undo-last` (which reads the in-place .bak), so it's an
  opt-in for pre-commit users who don't need single-step undo.
