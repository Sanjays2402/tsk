## Features (each its own commit)

1. `tsk graph --json --output --append --rotate N` (commit ebf533c)
   FIFO eviction primitive for the JSONL streaming-snapshot path.
   --rotate N caps the file to the most-recent N records, dropping
   oldest after each append. Atomic via write-to-.tmp + rename.
   9 new tests.

2. `tsk archive --json --output --append --rotate N` (commit eb7846b)
   Sister of the graph version (same tick). Same primitive, same
   shared helper, same crash-safe contract. 8 new tests.

3. `tsk wip --stale <duration>` (commit 4750f00)
   Staleness filter on `tsk wip` / `tsk in-progress`: surfaces only
   tasks running longer than threshold. The "I've been working on
   this too long" alert mode. Composes with --json. 10 new tests.

4. `tsk graph --json --include-pinned` (commit 7699226)
   SIXTH opt-in node field. Modeled as *bool so encoder can
   distinguish "flag off" from "flag on, task not pinned".
   --include-all updated to flip on pinned. 9 new tests.

5. `tsk graph --json --filter-completed-since <duration>` (commit a7e3d93)
   Recency-based subgraph filter. Trims envelope to nodes
   completed within window; root always preserved; edges to
   filtered-out nodes dropped. Envelope gains
   `filter_completed_since` marker field. Composes with
   --include-*, --reachable / --upstream-of, --compact-json,
   --append. 11 new tests.
